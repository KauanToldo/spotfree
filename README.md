# Spotfree 🎵

**Spotfree** é um aplicativo de música offline desenvolvido em Flutter, inspirado no Spotify. O projeto tem como objetivo proporcionar uma experiência de música fluida e prática, mesmo sem conexão com a internet. Utilizando o banco de dados SQLite, o app fornece um player de músicas com playlists variadas.

## 🚀 Funcionalidades

- **Player de Música Offline**: Reproduza suas músicas favoritas sem a necessidade de conexão com a internet.
- **Organização por Playlists**: As músicas disponíveis estão separadas em playlist por gênero músical.
- **Navegação por Músicas**: Navegue facilmente entre as músicas de suas playlists.
- **Controle de Reprodução**: Controle de reprodução completo (play, pause, anterior, próximo).
- **Armazenamento Local**: Todas as músicas e informações são armazenadas localmente utilizando SQLite.
- **Gerenciamento de usuários**: Faça seu cadastro e login para criar seu perfil próprio dentro do app.

## 🛠️ Tecnologias Utilizadas

- **Flutter**: Framework para o desenvolvimento do aplicativo.
- **Dart**: Linguagem de programação utilizada no Flutter.
- **SQLite (sqflite)**: Banco de dados local para armazenamento das músicas, playlists e usuários.

## 📱 Instalação e Uso

### Pré-requisitos

- Flutter SDK instalado.
- Um dispositivo Android, IOS ou emulador.

### Passos para Instalação

1. Clone o repositório:
    ```bash
    git clone https://github.com/KauanToldo/spotfree.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd spotfree
    ```
3. Instale as dependências:
    ```bash
    flutter pub get
    ```
4. Conecte seu dispositivo ou inicie um emulador.
5. Execute o aplicativo:
    ```bash
    flutter run
    ```
