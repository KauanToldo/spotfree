Spotfree 🎵
Spotfree é um aplicativo de música offline desenvolvido em Flutter, inspirado no Spotify. O projeto tem como objetivo proporcionar uma experiência de música fluida e personalizável, mesmo sem conexão com a internet. Utilizando o banco de dados SQLite, o app gerencia suas playlists e músicas de forma eficiente.

🚀 Funcionalidades
Player de Música Offline: Reproduza suas músicas favoritas sem a necessidade de conexão com a internet.
Gerenciamento de Playlists: Crie, edite e exclua playlists personalizadas.
Navegação por Músicas: Navegue facilmente entre as músicas de suas playlists.
Controle de Reprodução: Controle de reprodução completo (play, pause, anterior, próximo).
Armazenamento Local: Todas as músicas e informações são armazenadas localmente utilizando SQLite.
🛠️ Tecnologias Utilizadas
Flutter: Framework para o desenvolvimento do aplicativo.
Dart: Linguagem de programação utilizada no Flutter.
SQLite (sqflite): Banco de dados local para armazenamento das músicas e playlists.
